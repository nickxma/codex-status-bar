# Security

## Reporting a vulnerability

Please use GitHub's private [Report a vulnerability](https://github.com/nickxma/codex-status-bar/security/advisories/new) form. Do not open a public issue for a vulnerability that could put users at risk.

Include the affected version, the impact, and the smallest reproducible example you can provide. Remove API keys, credentials, private task names, message content, and unrelated logs.

## Supported versions

Security fixes target the latest published release. Older releases may not receive separate patches.
